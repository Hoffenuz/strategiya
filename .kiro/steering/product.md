# Product: Terra Revival

A calm, turn-based 2D pixel-art strategy game about healing a poisoned valley
(Solarpunk, ecosystem restoration). For all ages: no violence, and the Gentle
difficulty cannot be lost.

- Resources: **Gold** (salvage, Recyclers, restoration bounties, milestones) and
  **Energy** (the per-turn action budget).
- Goal: restore the difficulty's share of restorable land before the turn limit.
- Languages: English (source of every key) and Uzbek (Latin script). Every new
  UI string needs both.
- Accessibility is a requirement, not polish: WCAG contrast (4.5 : 1 text,
  3 : 1 large), color is never the only signal (add a shape, icon or text),
  UI scale up to 200 %, reduced motion, remappable keys, keyboard-only play.
- The spec is the source of truth: `.kiro/specs/terra-revival/`
  (`requirements.md` in EARS → `design.md` → `tasks.md`). Update it together
  with any behavior change.
